# Révisions STAPS — carnet de révisions

Copie **publique** du carnet de révisions présenté sur
[swanbadol.com/labo/revisions-staps](https://www.swanbadol.com/labo/revisions-staps).

Fiches du programme, planning, séries de QCM à questions mélangées avec
chronomètre, sujets de commentaire, et un historique qui trace la courbe des
scores. Tout est stocké dans le navigateur : aucun compte, aucune donnée qui
sort.

## Ce qui a été changé pour la mise en ligne

Cette copie est **générée** depuis la version privée par
`scripts/build-public.mjs`, qui échoue plutôt que de publier s'il retrouve une
des données retirées. L'original est fait pour une personne, et il en disait
bien plus que son prénom :

- le **prénom**, quatre fois, jusque dans la clé de stockage local ;
- le **tiers-temps**, neuf fois — c'est un aménagement d'examen, donc une donnée
  de santé ; le conseil de méthode qui la portait garde son sens sans elle ;
- la **session de rattrapage** et les « épreuves à reprendre » ;
- les **appréciations personnelles** (« ton point fort », « tu es déjà bon
  là-dessus »). Le tutoiement reste : c'est la voix de l'outil.

Le contenu de cours n'est pas touché.
