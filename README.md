# Révisions STAPS — carnet de révisions

Copie **publique** du carnet de révisions présenté sur
[swanbadol.com/labo/revisions-staps](https://www.swanbadol.com/labo/revisions-staps).

Fiches du programme, planning, séries de QCM à questions mélangées avec
chronomètre, sujets de dissertation, et un historique qui trace la courbe des
scores. Tout est stocké dans le navigateur : aucun compte, aucune donnée qui
sort.

Cette copie est **générée** depuis la version privée par
`scripts/build-public.mjs` : le prénom de la personne pour qui l'outil a été
construit y est retiré, et le script échoue plutôt que de publier s'il en
retrouve une occurrence. Le contenu de cours, lui, n'est pas touché.
